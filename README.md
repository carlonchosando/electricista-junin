# Sitio Web - Electricista en Junín

Este es un sitio web completo para "Electricista en Junín", un servicio de electricidad a domicilio, industrial y comercial ubicado en Junín, Buenos Aires, Argentina.

## Estructura del Sitio

El sitio web consta de las siguientes páginas:

1. **Página de Inicio (index.html)**: Presenta la empresa, servicios destacados y llamada a la acción.
2. **Página Nosotros (nosotros.html)**: Información sobre la historia, valores y características diferenciadoras.
3. **Página de Servicios (servicios.html)**: Detalle de todos los servicios ofrecidos.
4. **Página de Contacto (contacto.html)**: Formulario de contacto e información de contacto.

## Tecnologías Utilizadas

- HTML5 semántico
- Tailwind CSS para estilos
- JavaScript vanilla para interactividad
- Diseño completamente responsivo

## Requisitos para Completar la Implementación

### Imágenes Necesarias

Para que el sitio web se vea correctamente, es necesario agregar las siguientes imágenes en la carpeta `/img`:

1. `hero-electricista.jpg` - Imagen principal para la sección hero
2. `about-electricista.jpg` - Imagen para la página Nosotros
3. `servicio-instalacion.jpg` - Imagen para el servicio de instalaciones eléctricas
4. `servicio-reparacion.jpg` - Imagen para el servicio de reparaciones
5. `servicio-industrial.jpg` - Imagen para electricidad industrial
6. `servicio-comercial.jpg` - Imagen para electricidad comercial
7. `servicio-camaras.jpg` - Imagen para cámaras de seguridad
8. `servicio-paneles.jpg` - Imagen para paneles solares
9. `servicio-domotica.jpg` - Imagen para domótica

### Funcionalidades a Implementar

El archivo JavaScript (`js/main.js`) ya incluye:
- Menú móvil (hamburguesa)
- Scroll suave para enlaces internos
- Botón de volver arriba
- Validación del formulario de contacto
- Lazy loading para imágenes

## Cómo Probar el Sitio

Para probar el sitio localmente, simplemente abra los archivos HTML en su navegador. Para una experiencia completa:

1. Agregue las imágenes mencionadas anteriormente en la carpeta `/img`
2. Para implementar el mapa en la página de contacto, reemplace el placeholder con un iframe de Google Maps

## SEO y Metaetiquetas

El sitio incluye metaetiquetas optimizadas para SEO con palabras clave relevantes para servicios eléctricos. Cada página tiene su propia descripción y título optimizados.
